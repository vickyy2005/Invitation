# 💍 Priya & Shinoj - Royal Wedding Invitation Web Application

A luxury, interactive, mobile-responsive wedding invitation web application crafted with a Royal Cream and Royal Brown theme, soft gold metallic accents, and realistic palace gate entrance animations.

---

## ✨ Features

- 🏛️ **3D Royal Double Doors Entrance**: Interactive double doors with real-time 3D opening animation and central royal seal medallion ("Tap to Open").
- 🎀 **Royal Cream Silk Curtains Reveal**: Elegant layered valance and parting curtains that smoothly open after the doors.
- 💎 **Glassmorphic Sticky Navigation**: Translucent frosted glass navbar with continuous celebratory gold light beam trim and responsive drawer.
- ⏳ **60-Day Countdown Timer**: Live ticking countdown timer starting with a 60-day timeline.
- 💌 **Neumorphic RSVP Form**: Authentic soft UI form with debossed inputs, segmented attendance buttons, and guest count selection.
- 📜 **Wishes Wall & Local Storage**: Dynamic message board for guest blessings and warm wishes with local persistence.
- 📸 **Photo Gallery & Lightbox**: Interactive grid of precious moments with full-screen lightbox preview.
- 📍 **Venue & Location Details**: Google Maps integration, directions button, and ceremony schedule timeline.
- 🎵 **Background Music Controller**: Ambient background soundtrack controller with animated audio equalizer waves.

---

## 🚀 Getting Started

### Local Setup
Run the lightweight built-in Node.js server:

```bash
node server.js
```

Then open your browser and navigate to:
```
http://localhost:8765
```
